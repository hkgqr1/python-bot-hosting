## Как запустить бота: от регистрации до первой строки в логах

Регистрация занимает минуту: аккаунт в панели, выбор тарифа, оплата. Сервер появляется в среднем через 4 секунды. Дальше остаётся загрузить код.

1. Загрузите файлы бота и requirements.txt через файловый менеджер или по SFTP (FileZilla, WinSCP).
2. Укажите «Файл запуска»: по умолчанию это run.py, можно указать bot.py или любой другой файл.
3. Запустите сервер. Библиотеки из requirements.txt установятся автоматически при каждом старте.
4. Положите токен в .env рядом с кодом и читайте его через python-dotenv, чтобы он не попал в репозиторий.
5. Смотрите логи в консоли панели: там видно, поднялся ли polling и какие ошибки летят.

aiogram, python-dotenv, sqlalchemy и aiosqlite уже стоят по умолчанию, дублировать их в requirements.txt не обязательно. Остальное из pip (python-telegram-bot, Telethon, Pyrogram, discord.py) подтянется из requirements.txt или из поля «Библиотеки» в настройках. Ошибка ModuleNotFoundError почти всегда означает, что нужную библиотеку забыли вписать в requirements.txt: добавьте строку, перезапустите сервер, ошибка уйдёт.

Git тоже работает, но вручную. При старте сервера выбираете Bash-консоль, там уже установлен git, доступны git clone и git pull. Автоматической сборки по push, как в PaaS, здесь нет: обновления кода это либо SFTP, либо команды в консоли.

## Ограничения, о которых узнаёшь из FAQ

Часть условий видна только в разделе частых вопросов, и два из них способны изменить выбор языка и архитектуры.

- **Исходящая почта по SMTP закрыта** на портах 25, 465, 587 и 2525. Если в сценарии есть письма с подтверждением, отправлять их придётся через HTTP API почтового сервиса.
- **Node.js на тарифах для ботов недоступен.** Только Python 3.12, так что вторая половина проекта на Telegraf здесь не поднимется.
- **Торренты запрещены**, а защита от перебора паролей ограничивает частые подключения к чужим SSH и базам данных. Боту, который ходит в свою базу на том же сервере, это не мешает; парсеру с десятками внешних подключений стоит проверить заранее.
- **Досрочное удаление возвращает деньги на внутренний баланс**, а не на карту. Потратить их можно на новый сервер или следующее продление, вывести наружу нельзя.
- **Повышение тарифа не требует пересоздания сервера.** Файлы и настройки остаются на месте, доплата идёт за оставшийся период.
